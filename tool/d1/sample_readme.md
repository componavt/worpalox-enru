# sample_readme — как читать этот пакет (D1)

Что это: результат первого прохода D1 по корпусу talp (881 строк) —
технический аудит + содержательная разметка 300 строк + сцены, ловушки и
аудит выравнивания. Подготовил агент ZCode (GLM) 2026-11-22; редакторские
вердикты — слой агента поверх данных НКРЯ (CC BY-NC-SA 4.0 наследуется
разметкой).

## Как готовилось

- Скрипты: `tool/talp_audit.py` (аудит + выборка), `tool/d1/make_pilot_csv.py`
  (pilot_lines + issues), `tool/d1/make_pilot_tables.py` (сцены, ловушки,
  alignment_audit). Версия данных: снимок RNC enru_aligned в
  assets/corpus; коммит main f55fcce.
- Порядок работы: скриптовый аудит всех 881 строк → чтение 300 строк
  выборки (плюс 45 бонусных) через reading_pack.txt → редакторские
  вердикты → CSV.
- Что посчитал скрипт: все числа talp_summary.md (связи, границы,
  дубликаты, распределения, сопоставление уровней). Что предложил агент:
  роли, качество переводов, PLAY/CONTEXT/SKIP, сцены, ловушки. Что
  подтвердил человек: пока ничего — пакет идёт на внешнюю проверку.

## Правила индексации

- talp: 1-based по whitespace-токенам enru.src / enru.tgt; «i-j» надёжно,
  «ipj» вероятно; оба разделителя встречаются в одной строке.
- Индексация игры: PuzzleToken.id = позиция в правильном порядке с нуля;
  при импорте нужен сдвиг −1 и перенос только confirmed-связей.

## Критерии отбора строк

Окна: 1–33 (инструкции/буклеты), 148–180 (Оз/Баум + Брэдбери),
340–372 (Кристи/Акойройд + Пуаро), 480–512 (Дойл), 620–652 (современная
проза/эссе), 830–862 (смешанная). Вокруг уровней: ±2 строки от 28
найденных уровней. Случайные: 50 с seed 20261122. Прочитанная для
контекста строка не считалась размеченной; в CSV каждая строка помечена
selection = window | around | random | bonus.

## Что проверять внешнему читателю

1. Сходимость: числа talp_summary.md ↔ audit_summary.json ↔ CSV.
2. Выборка: не подглядывает ли «витрина» (review_cases) мимо системной
   проблемы — сверить с issues.csv (32 записи).
3. Ловушки: сколько BOTH против LLM; слепая проверка naturalness для
   ACCEPTABLE.
4. Оценку стоимости масштабирования: 300 строк ≈ X часов агента → 881.
